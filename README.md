# Data-Transformation-and-Data-Modelling-POWER-BI

# Project Overview
This project processes, cleans, transforms, and models e-commerce order transactions, itemized sales records, and sales performance targets using Power Query Editor and Power BI Desktop.

# Objectives
1. import data
2. data transformation
3. merging data
4. handling missing and duplicate data
5. sorting and filtering
6. grouping and aggregating data
7. data modelling
